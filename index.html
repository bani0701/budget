🔗 가계부 공유

가족·친구와 같은 가계부를 함께 작성할 수 있어요.

공유를 켜려면 데이터를 담아둘 무료 저장소(Firebase)를 한 번만 연결하면 돼요. 5분이면 끝나고, 이후엔 링크만 보내면 됩니다.
이미 쓰던 가계부가 있나요? 다른 기기·브라우저에서 받은 초대 링크를 붙여넣으면 그 가계부를 그대로 이어서 볼 수 있어요.
아직 웹 주소가 없어요. 이 파일을 인터넷에 한 번 올려야 상대방이 링크를 열 수 있습니다. 아래 안내를 따라 주소를 만들고 붙여넣어 주세요.
🌐 웹 주소 만드는 법 (무료, 한 번만)
  1. 파일 앱에서 이 가계부 파일 이름을 index.html 로 변경 (길게 눌러 → 이름 변경)
  2. github.com 가입·로그인 → 우측 상단 + → New repository
  3. 이름 아무거나 입력, Public 선택 → Create repository
  4. 첫 화면의 uploading an existing file 탭 → index.html 선택 → Commit changes
  5. Settings → Pages → Branch를 main / (root) 로 두고 Save
  6. 1~2분 뒤 생기는 https://아이디.github.io/저장소이름/ 주소를 아래에 붙여넣기
  1. 폴더를 하나 만들고, 가계부 파일 이름을 index.html 로 바꿔 그 안에 넣기
  2. 크롬에서 app.netlify.com/drop 접속 (무료 가입)
  3. 그 폴더를 화면에 끌어다 놓기 → 몇 초 뒤 주소 생성
  4. 생긴 https://OOO.netlify.app 주소를 아래에 붙여넣기
이 방법은 폴더를 끌어다 놓는 방식이라 휴대폰에서는 안 돼요. 휴대폰만 쓰신다면 왼쪽 탭을 보세요.
문자 버튼을 누르면 휴대폰 문자 앱이 링크가 적힌 채로 열려요. 보내기만 누르면 됩니다.
가족 기록은 그대로 두고 빈 가계부 앱만 다른 사람에게 보낼 수도 있어요. 받은 사람은 자기 가계부를 새로 쓰게 되고, 우리 기록은 보이지 않습니다.

🚀 공유 저장소 연결

Google 계정만 있으면 무료예요. 한 사람만 하면 됩니다.

  1. console.firebase.google.com 접속 → 프로젝트 만들기 (이름 아무거나, 애널리틱스는 꺼도 됨)
  2. 왼쪽 메뉴 빌드 → Realtime Database → 데이터베이스 만들기
  3. 위치는 싱가포르(asia-southeast1) 추천 → 테스트 모드로 시작 선택 → 사용 설정
  4. 화면 위에 보이는 주소(https://...firebasedatabase.app)를 복사해서 아래에 붙여넣기
  5. 연결 후 규칙 탭에서 아래 내용으로 바꾸고 게시하면 30일 뒤 만료되지 않아요
{ "rules": { "books": { "$book": { ".read": true, ".write": true } } } }
주소를 아는 사람은 이 가계부를 열 수 있어요. 링크는 가족·친구에게만 보내시고, 계좌·비밀번호 같은 정보는 메모에 적지 마세요.
